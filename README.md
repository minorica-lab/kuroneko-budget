# クロネコちゃんの家計簿

暦月の家計簿と翌月の資金計画を試せる静的デモです。初期データはすべて架空です。入力内容はブラウザのローカルストレージに保存します。外部APIやアカウント登録は不要です。

## ローカルで起動

ファイルを展開したディレクトリで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開きます。

## GitHub Pagesで公開

ZIPを展開し、新規リポジトリのルートにファイルを配置します。リポジトリの **Settings → Pages** で公開元を **Deploy from a branch** に設定し、公開ブランチと **/ (root)** を選びます。

## 主な機能

- 暦月の支出集計と、25日〜翌24日の給与集計
- カード利用と引落精算の区別
- 残高・未払金・予算から自由に使える金額を計算
- 翌月の資金計画と、NISA・ローン返済の比較
